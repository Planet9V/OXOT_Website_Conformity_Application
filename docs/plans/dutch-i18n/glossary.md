## Style rules
- Address the reader as **u** / **uw**.
- Sentence case for headings (Dutch convention), not Title Case.
- Keep numbers, dates, product/reg names, and code identifiers unchanged.
- Preserve every interpolation, JSX tag, prop, className, and link target — translate visible text only.
- Currency stays as shown (€). Percentages/units unchanged.
